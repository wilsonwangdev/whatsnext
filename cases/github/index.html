GitHub微软 · 整体收购

微软以 75 亿美元全股票收购 GitHub，明确承诺「独立运营、保持开发者优先、维持开放平台」。七年后，GitHub 被并入微软 CoreAI 组织，CEO 离职且不再补位——三条承诺里最硬的那一条，以重组的形式结束。

背景：代码托管的事实标准

GitHub 于 2008 年上线，把 Git 从命令行工具变成了社交化的协作平台：fork、pull request、issue、star，这套词汇后来成了整个行业的通用语。到 2018 年微软提出收购时，官方口径是 2,800 万开发者——它已经是绝大多数开源项目的默认家园，也是企业私有代码的主要托管地。

这个位置带来一个结构性矛盾：它是开发者的中立公共空间，但它是一家需要赚钱的公司。 微软提出收购时，社区最担心的不是技术，而是这个中立性会不会被商业化侵蚀。

交易：75 亿美元，全股票

2018 年 6 月 4 日，微软宣布以 75 亿美元全股票收购 GitHub。10 月 26 日交割完成，GitHub 作为独立子公司运营，Nat Friedman 出任 CEO，联合创始人 Chris Wanstrath 转为微软 Technical Fellow。

公告里最关键的是一句话，写在提交给 SEC 的投资人演示材料里：

GitHub will retain its developer-first ethos, operate independently and remain an open platform.

三个承诺：保持开发者优先、独立运营、维持开放平台。 这句话后来成了所有「大公司收购开发者工具」交易的参照话术——几乎每一笔同类交易都会复述类似的三段式。

之后：三条承诺，三种结局

独立运营 —— 已终结。 2025 年 1 月，微软成立 CoreAI 组织，Nadella 明确把 GitHub 列为该组织下的开发者工具之一。8 月 11 日，CEO Thomas Dohmke 宣布离职创业，备忘录里写着：

GitHub and its leadership team will continue its mission as part of Microsoft’s CoreAI organization.

独立子公司变成一个大组织里的一个部门，独立运营的实体边界就此消失。这是三条承诺里最硬的一条，也是唯一有明确终止时点的一条。

开放平台 —— 基本兑现。 平台没有对行业设限，2025 年 8 月的官方数据是 1.5 亿开发者和 10 亿仓库与 fork。免费层不但没收缩，2019 年 1 月还扩大到无限私有仓库。

开发者优先 —— 部分兑现。 这一条最难判。正面证据是免费额度持续扩大、Actions 提供免费分钟数；反面证据是 Copilot：它用公开仓库的代码训练模型并商业化，2022 年 11 月引发集体诉讼，原告主张这违反了开源许可证的署名与条款要求。

团队规模：一个必须承认查不到的数字

按本站规则，团队规模应记录在 checks 里。但这个案例查不到可靠数字。

微软从未在财报里单独披露 GitHub 的员工数。第三方劳动力数据给出的结果差异过大：Revelio Labs 报 2026 年 3 月约 2,669 人、2023 年 2,403 人；Wikipedia 引用 3,787 人；Unify 按职业档案统计到 6,172 人。三个数字最大相差 2.3 倍，口径里是否含承包商、外包、海外实体无法确认。

唯一能确认的是方向而非绝对值：2023 年 2 月裁员 10%，并全面转为远程办公，官方未披露受影响人数的绝对值。

所以这一页不写具体人数，只写「无官方披露」。这不是偷懒——在这个案例里，填一个看起来很精确的数字，比留空更误导。

为什么值得研究

  • 这是「独立运营」承诺的起源样本。 2018 年之后，几乎每一笔大公司收购开发者工具的交易都会复述这套话术。要判断后来者是否真诚，得先看清这一笔是怎么收场的。
  • 承诺的硬度差别很大。 「开放平台」可以被平台数据验证，「独立运营」有明确的组织边界可查，而「开发者优先」至今没有可量化定义——能被验证的承诺才可能被判为 broken，模糊的承诺永远停在 partial。
  • 独立性的终结不需要出售。 GitHub 没有被转卖、没有关停、产品还在增长，但「独立运营」这条承诺在 2025 年 8 月结束了。对用户来说，组织架构调整和交易一样，都是实质性的所有权变化。

公开承诺核对

GitHub 将保持独立运营（operate independently）。

未兑现出处 ↗

2025 年 8 月 11 日，GitHub 被并入微软 CoreAI 组织；CEO 离职且未任命继任者，独立运营的实体边界消失。

GitHub 将保持开放的开发者平台（remain an open platform）。

已兑现出处 ↗

平台仍对全行业开放，2025 年 8 月官方口径为 1.5 亿开发者、10 亿仓库；免费额度与公开仓库政策未收紧。

GitHub 将保留开发者优先的理念（retain its developer-first ethos）。

部分兑现出处 ↗

2019 年免费私有仓库、Actions 免费额度等方向一致；但 Copilot 以公开代码训练并商用，触发 2022 年集体诉讼，部分开发者认为与「开发者优先」相冲突。

收购不会改变 GitHub 的定价与开放性（公告与高管公开表态）。

已兑现出处 ↗

免费层持续扩大而非收缩，是这笔交易里兑现程度最高的部分。

待核验的问题

  • GitHub 的员工数没有官方披露。第三方估算差异极大（2,669 / 3,787 / 6,172 三种口径），无法判断哪个包含承包商或外包，因此本页不采用任何单一数字。
  • 2023 年 2 月裁员 10% 的绝对人数未公开，无法计算团队规模的净变化。
  • 并入 CoreAI 之后，GitHub 是否还保有独立的产品与定价决策权，目前没有公开说明。
  • Copilot 集体诉讼在 2024 年被驳回多数指控，剩余指控的最终结果尚未见公开判决记录。
  • 「开发者优先」缺少可量化定义，判定为 partial 依赖具体事件而非指标。
