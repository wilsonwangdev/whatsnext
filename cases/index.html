Deno

→Cloudflare

2026 年 10 月，Deno 团队整体加入 Cloudflare。运行时再支持一年后停止开发，Deno Deploy 六个月后关停，JSR 迁移到 Cloudflare。一个开源运行时给出了明确的退场时间表。

02 / 人才收购团队加入

Dioxus

→Cognition

2026 年 9 月，Cognition 宣布 Dioxus 团队整体加入，继续支持 Dioxus、Blitz、Taffy 与 Subsecond。交易没有改变许可证，却让多个关键 crate 的发布权限转移到了收购方。

2026.09.10未披露证据 A
03 / 整体收购已交割

Bun

→Anthropic

Anthropic 于 2025 年 12 月收购 Bun，理由是 Claude Code 的基础设施需要更快的运行时。MIT 许可证保留，但 2026 年 5 月的一次 AI 辅助 Rust 重写改变了项目的技术路线。

2025.12.02未披露证据 A
04 / 整体收购已交割

HashiCorp

→IBM

IBM 以约 64 亿美元收购 HashiCorp，2025 年 2 月完成。交易没有让 Terraform 的许可证回到 MPL——2023 年的 BUSL 变更被完整保留，OpenTofu 分叉继续存在。

2025.02.27$6.4B证据 A
05 / 整体收购已终止

Figma

→Adobe

Adobe 于 2022 年宣布以约 200 亿美元收购 Figma，15 个月后因监管受阻终止。Figma 保持独立，并于 2025 年 7 月上市，首日市值约 676 亿美元。

2022.09.15$20B证据 A
06 / 整体收购已交割

Netless

→声网 Agora

上海团队把实时互动白板做成可嵌入的 White SDK，2020 年 11 月被刚上市的声网收购 100% 股权。能力被并入 RTE 产品线，独立品牌随后淡出。

2020.11.27未披露证据 B
07 / 整体收购已交割

npm

→GitHub（微软）

GitHub 于 2020 年 3 月宣布收购 npm，4 月完成。公共 registry 保持免费，付费的 npm Enterprise 在一年后停止支持，客户迁往 GitHub Packages。

2020.04.15未披露证据 A
08 / 整体收购已交割

Teambition

→阿里巴巴

国内最早一批协同办公 SaaS 之一。2018 年接受阿里 1 亿美元投资，四个月后阿里主体持股 100%；团队随后转向阿里云盘，创始人齐俊元于 2023 年离开阿里。

2019.03.28未披露证据 B
09 / 整体收购已交割

GitHub

→微软

微软以 75 亿美元全股票收购 GitHub，明确承诺「独立运营、保持开发者优先、维持开放平台」。七年后，GitHub 被并入微软 CoreAI 组织，CEO 离职且不再补位——三条承诺里最硬的那一条，以重组的形式结束。
